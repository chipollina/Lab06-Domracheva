## Что изучено 
- Цикл `for` применяется, когда количество повторений известно заранее; в нём три части: начальное значение счётчика, условие продолжения и шаг.
- Цикл `while` проверяет условие **до** выполнения тела, а `do while` — **после**, поэтому `do while` гарантированно выполнится хотя бы один раз.
- Операторы `break` и `continue` управляют циклом изнутри: `break` досрочно завершает цикл, а `continue` пропускает текущую итерацию и переходит к следующей.
- Для накопления результата переменную-накопитель (сумму, счётчик) объявляют **до** цикла, а изменяют **внутри** него.
